# Security policy

Hydra is an unofficial community fork of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). It runs commands that a model chooses, on your machine, so read the [safety notice](SAFETY.md) before you use it.

## Report a vulnerability

Report it privately: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for it.

Include what is affected, how to reproduce it, and the release or commit you tested. The conversation stays private until a fix is published.

If the problem also affects unmodified DeepSeek Harness, tell its maintainers too, through the [upstream repository](https://github.com/deepseek-ai/deepseek-harness).

## Supported versions

Fixes go to the `main` branch and the next release. Older releases are not patched.
