Usage: hydra [--profile] <name> [options] [app-args...]
       hydra plugin --profile <name> <pnpm-args...>

hydra: boot a Hydra profile — an ordered stack of plugin-bundle patch layers
under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 hydra --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $DSH_HOME/profiles to boot
  --from-default-profile <name>  replace a custom profile with a fresh copy of a
                                 shipped profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  hydra web                                 boot the web profile (same as: hydra --profile web)
  hydra rescue --from-default-profile web
                                            recreate rescue from the shipped web template, then boot it
  hydra headless "run the tests"            answer one task, print the result, and exit
  hydra tui --patch ./extra.yml             boot a custom profile with one extra overlay
  hydra tui --resume <session>              arguments after the launcher flags reach the app
  hydra web --help                          the web app's own flags and help
  hydra plugin --profile tui add <package>  install a plugin into the tui profile

dsh is the same command under its earlier name.
